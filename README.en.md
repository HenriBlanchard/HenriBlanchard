**🤠 Cowboy's Redemption** · *Personal project*

A Wild West spelling game (in French): you hunt down an outlaw cowboy on the run for crimes against spelling. In each telegram, the mistakes are replaced by drop-down menus; picking the right spelling earns points that unlock medals, from Tenderfoot to Sheriff. The game runs fully offline with no server or dependencies, saves progress in the browser, and its logic is unit-tested with Node.js.
