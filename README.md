### 🚀 Projet en vedette : [R\*mble](https://rmble.ca)

Une application de clavardage pour les communautés, les amis et les gamers : serveurs avec canaux, messages privés et statuts en direct (en ligne, occupé, absent).
Disponible sur ordinateur et sur mobile, développée par une équipe de sept personnes.
